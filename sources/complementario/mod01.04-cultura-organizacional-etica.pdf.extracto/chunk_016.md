Modelo de Fogg – Introducción
Motivación
Riesgo, identidad, consecuencia
Capacidad
Habilidad, simplicidad, guía
Disparador
Recordatorio o señal visual
El modelo de comportamiento de Fogg establece que para que ocurra un comportamiento deseado, deben coincidir tres 
elementos: suficiente motivación, capacidad adecuada para realizar la acción y un disparador efectivo que active el 
comportamiento en el momento oportuno.
Esta fórmula (Comportamiento = Motivación + Capacidad + Disparador) ofrece un marco práctico para diseñar intervenciones 
que promuevan comportamientos positivos en protección de datos.
Behavior = Motivation + Ability + Prompt
