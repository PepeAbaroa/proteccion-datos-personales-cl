Minimización de la 
asimetría de 
información 
La asimetría de información se define 
como la situación en la que una de las 
partes involucrada en una transacción 
tiene más o mejor información sobre esta 
que la otra. Para que exista una relación 
de confianza entre el responsable y el 
sujeto de datos, este debe conocer y 
entender la naturaleza del tratamiento. El 
uso de este patrón se traduce en 
minimizar la cantidad y tipo de datos 
obtenidos del usuario para que sólo se 
procesen los datos personales requeridos 
para el propósito perseguido y establecer 
políticas claras y concisas fácilmente 
comprensibles por el usuario, reduciendo 
así el desequilibrio responsable – sujeto 
de datos.
